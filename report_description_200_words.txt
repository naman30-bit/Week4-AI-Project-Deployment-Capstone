This project, titled Iris Species Prediction API, was developed for the Week 4 AI Project Deployment and Capstone task of the Yuvaintern Machine Learning Internship. Its purpose is to demonstrate a complete beginner-friendly machine-learning workflow, starting with data preparation and ending with a deployed prediction API. The project uses the public Iris dataset available through Scikit-learn. It contains four numeric flower measurements: sepal length, sepal width, petal length and petal width. The target is one of three Iris species: setosa, versicolor or virginica.

The project is implemented in Python using Pandas, Scikit-learn, Joblib and Flask. First, the dataset is loaded and its feature columns and target labels are separated. The data is divided into training and testing sets using an 80:20 split with stratification so that class proportions are maintained. A Scikit-learn Pipeline combines StandardScaler preprocessing with a Random Forest classifier. The pipeline is trained on the training data and evaluated on the held-out test data. Accuracy, macro precision, macro recall and macro F1-score are calculated. A confusion matrix and classification report are also saved in the outputs folder.

After evaluation, the complete fitted pipeline is serialized to a Joblib file. Saving the preprocessing step together with the classifier ensures that new API inputs receive the same scaling transformation used during training. A Flask application loads the saved model and provides three endpoints: the home endpoint, a health-check endpoint and a prediction endpoint. The prediction endpoint accepts a JSON object containing all four flower measurements, checks for missing or non-numeric values, and returns the predicted species together with class probabilities. Basic automated tests are included to check the API routes, a valid prediction and invalid input handling.

The README file explains how to create a virtual environment, install dependencies, train the model, start the Flask server and test the API using Windows PowerShell. The project demonstrates model serialization, application deployment concepts, API input validation and project documentation. It is an educational demonstration based on a public sample dataset and is not intended for high-stakes use.
